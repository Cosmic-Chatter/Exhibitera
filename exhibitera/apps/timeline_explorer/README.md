# Timeline Explorer
Timeline Explorer builds touchscreen timelines from a spreadsheet.

## Configuration

### Hardware control
By default, Timeline Explorer responds to taps and swipes on the touchscreen. By enabling hardware control, you can also interact using the keyboard. This allows you to integrate Timeline Explorer with physical buttons that spoof keyboard keys, such as by using a Makey Makey.

| Action                      | Keyboard input                                                     |
|-----------------------------|--------------------------------------------------------------------|
| Move the timeline           | Left/Right arrow keys (landscape) or Up/Down arrow keys (portrait) |
| Switch to the next language | l key (lowercase "L")                                              |
| Change text size            | o key (decrease) or p key (increase)                               |

### Formatting timeline text
You can format text by using [Markdown](https://www.markdownguide.org/basic-syntax/) when entering text into your spreadsheet. You can also set overall font, size, and color during setup.
