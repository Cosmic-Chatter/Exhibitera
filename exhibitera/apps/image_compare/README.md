# Image Compare

Image Compare creates compelling before-and-after sliders that enable visitors to compare two images.

## Configuration
You can include up to eight pairs of images in one instance of Image Compare.

### Hardware control
By default, Image Compare responds to taps and swipes on the touchscreen. By enabling hardware control, you can also interact using the keyboard. This allows you to integrate Image Compare with physical buttons that spoof keyboard keys, such as by using a Makey Makey.

| Action                                       | Keyboard input                                                   |
|----------------------------------------------|------------------------------------------------------------------|
| Select an image pair from the home screen    | Use the number keys 1 - 8 to select the corresponding image pair | 
| Swipe between the two parts of an image pair | Left and right arrow keys                                        |
| View/hide the Info Pane for an image pair    | "i" key                                                          |
| Return to the home screen                    | Space bar                                                        |

## Supported image types
Exhibitera Apps recognizes the following image file formats:

| Type  | Recognized formats                                          |
|-------|-------------------------------------------------------------|
| Image | `bmp`, `heic`, `jpeg`, `jpg`, `png`, `tif`, `tiff`,  `webp` |
